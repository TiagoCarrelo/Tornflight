Sobre as fontes de dados

Stocks estrangeiros: YATA API (yata.yt/api/v1/travel/export/) — dados crowd-sourced pela comunidade Torn, atualizados sempre que um utilizador com scripts YATA viaja.

Nomes & preços de mercado: Torn API (api.torn.com/torn/?selections=items) — dados oficiais de todos os items.

Limitação: O Torn não tem API pública para stocks estrangeiros em tempo real. O YATA é a melhor fonte disponível.
