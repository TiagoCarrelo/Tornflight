Instalar como App

Adiciona ao ecrã inicial para usar como app nativa.

iOS Safari: Partilhar → Adicionar ao Ecrã Inicial
Android Chrome: Menu ⋮ → Adicionar ao ecrã inicial
Desktop Chrome/Edge: ícone ⊕ na barra de endereço

Sobre as fontes de dados

Stocks estrangeiros: YATA (yata.yt/api/v1/travel/export/) — sem key necessária.

Items e preços: Torn API torn/items

Estado de viagem: Torn API user?selections=travel,basic

Jogadores no destino: YATA export inclui dados de viajantes registados. A Torn API não expõe quem está abroad — esta é a melhor fonte disponível.
